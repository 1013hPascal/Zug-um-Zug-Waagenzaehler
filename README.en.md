# Zug um Zug Scale Counter

[Deutsch](README.md) | English

The program counts the number of scales per player in the board game Zug um Zug and provides information about the progress of the game.

## Download
There is an exe for Windows.

## Features
- Counts the number of scales per player.
- Provides information on how many scales a player still has left.
- Offers a voice output.
- Uses sound effects to draw attention at specific points in the game:
  - When half of the scales have been used.
  - When the first player is close to the end of the game.
- Includes a winner ceremony where the result is read aloud.
- Supports blind players by providing information on the number of scales they have placed.

## Operation
All keys can be confirmed with the Space bar. Usually, the Enter key also works for confirmation.

## System Requirements
There is an exe for Windows.

## Tools and Libraries
PySide6, dataclasses, pygame, win32com.

## Windows Warnings
Windows may warn you with "Your PC might be at risk" because the exe is not signed. Select "More info" and then "Run anyway".
